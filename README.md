# ClearNav III Screensaver SDK — releases

The kit for people who write screensavers for the ClearNav III flight computer: one release per SDK version, each carrying the signed and notarized DMG (the template, the samples, the scripts and CheckSaver), its SHA-256 sidecar, and the SDK guide as a PDF in a screen edition and a printing edition.

**Download:** the Releases page of this repository. Always check the DMG against its `.sha256` sidecar.

**History.** SDK 2.0, 2.1 and 2.2 were first published in `fizzsnob/clearnav-releases` (2026-09-09 to 2026-09-10). On 2026-10-07 they moved here, asset for asset (the 2.0 and 2.1 releases gained the sidecar their first publish lacked), so that `clearnav-releases` serves the flight computer's own software and data alone. The old entries remain there, marked pre-release, so existing links keep working.

**Versions.** The SDK version (2.x) is the kit's; the SDK *contract* (1.1, 1.2 …) is the interface a screensaver is written against — the guide of each release names both.
